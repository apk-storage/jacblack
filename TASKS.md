## Сделано 18.08.2026

- [x] **Аниме не находилось из карточки с годом.** По «Tsue to Tsurugi no
      Wistoria S2» с `year=2024` выдача была пуста, без года — четыре раздачи.
      Причина: правило «человек указал год, а у раздачи год не разобран —
      выбрасываем» (ставилось против сериалов-тёзок в карточке фильма
      «Одиссея» 2026). У аниме года в названии не бывает вовсе —
      `[SubsPlease] ... S2 - 04`, — и под нож попадала вся аниме-выдача.
      Послабление: раздача без года проходит, если карточка объявила себя
      сериалом/аниме И в названии есть номер сезона или серии.
      **Проверено:** запросом Сергея — 0 → 4 раздачи; `Sakamoto Days` 0 → 57,
      `Dandadan` 0 → 44; карточка фильма «Одиссея» 2026 отдаёт 12 раздач, все
      2026 года (старая беда не вернулась); 768 тестов зелёные, из них 4 новых
      в `tests/JacBlack.Tests/Search/AnimeWithoutYearTests.cs`.
      Замечено попутно: у `FilterByCardTitle` есть «последний рубеж» — при
      пустом строгом отборе он отдаёт совпавшие по названию записи без года.
      Тесты на это правило обязаны иметь якорную раздачу с годом, иначе
      проверяют рубеж, а не правило.
